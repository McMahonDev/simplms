# Sample SCORM packages

`RuntimeBasicCalls_SCORM12.zip` and `RuntimeBasicCalls_SCORM20043rdEdition.zip` are the
"Run-time Basic Calls" Golf Examples by Rustici Software, downloaded from
https://scorm.com/scorm-explained/technical-scorm/golf-examples/ and used under the
Creative Commons Attribution 3.0 License. `pnpm db:seed` imports both into the
"Golf Fundamentals" course.
